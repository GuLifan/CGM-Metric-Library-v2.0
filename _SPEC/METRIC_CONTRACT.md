# 计算合同 v2.0.0

生效日期：2026-11-04。最新会议裁定与本合同共同约束计算；参考验收状态见04_Manuals/VALIDATION.md。

2026-11-09 补充裁定见 [事件时长与窗口覆盖](DECISIONS_20261109.md)。原始五分钟源与一分钟聚合源均按规划槽计算事件时间。覆盖及各范围分钟均以组首归属后的窗内支持时间计算。

## 1. 通用输入、单位和充分性

- 原始列保留 `glucose_raw`，清洗列为 `glucose_clean`。确认错误码、设备无效标识、0 和负值均设 NA 并记录原因；无错误标识的有效正值 \<1.8 mmol/L 保留原值及 `below_1p8_flag`，作为质量证据。
- 按时间升序建网格并保留空槽。按 D-09，同一时刻只有一种有效清洗值就采用该值；两种及以上有效值冲突置 NA；全无效时置 NA。保留重复组的全部源行、清洗原因与代表行号。按 D-06，标称一分钟源在固定五分钟槽内出现超过五个不同时刻时停止该文件，记录槽边界、条数与实际间隔。
- 标准单位为 mmol/L。百分数 canonical 字段为 0–100，并在变量名加 `_pct`；0–1 比例另名 `_prop`。指标均写入适用窗口、单位、配置与缺失原因。
- 所有研究窗左闭右开；一般、日级、日夜子窗 coverage 至少70%，子窗独立判断。覆盖不足时正式结果 NA、QC 保留。充分观测且没有事件时事件数/标签为0，不以 NA 表示“未发生”。
- **\[Lifan 本轮重新裁定\]** 一分钟源以排序后最早原始时刻固定五分钟分组；组内有效正值取均值，四零一有效取唯一值；代表时刻固定为来源组首规划时刻，相邻组相差五分钟。窗口归属及连续事件均依据该组首时刻；首有效原始时刻另存 QC，Sparse 独立使用原始有效读数及其时刻。原始五分钟设备同槽多个不同实际有效读数整槽 NA、保留原始证据并标 QC。
- 固定医学参数、项目可调窗口/coverage、研究特异锚点分层记录；配置快照及 SHA256 随运行输出。

## 2. 甲方修订稿的 32 类指标清单

以下按 `01.md` 的编号列出公式、正式语义和依赖。连续类默认只用窗口中充分且有效的 `glucose_clean`。

| \# | 指标族 | 计算或取值规则 | 输出、边界及QC |
| --------------------: | ----------------- | ----------------- | ----------------- |
| 1 | MEAN | 窗口全部有效值算术均值 | mmol/L；附窗口覆盖 |
| 2 | SD | 样本标准差，分母 n−1 | mmol/L；有效值不足为 NA |
| 3 | CV | SD/MEAN×100 | `CV_pct`；单位百分数 |
| 4 | GMI | `3.31 + 0.02392 × (MEAN_mmol_L × 18)` | CGM-derived GMI，%；短窗解释有限，不称等效 HbA1c |
| 5 | LBGI | 全部有效读数逐个作 Kovatchev 低风险变换，再 pooled 平均 | 不逐日等权；不硬编码风险等级标签 |
| 6 | HBGI | 全部有效读数逐个作高风险变换，再 pooled 平均 | 同 LBGI |
| 7 | ADRR | 每个覆盖合格日的 max low-risk + max high-risk，再跨合格日平均 | 截断日按交集分母并标记；另输出仅完整自然日的敏感性 ADRR、有效日数与差异；日级70%门槛 |
| 8 | MODD | 相邻自然日同钟点有效值绝对差，所有有效 matched pairs 平均 | 只配日期恰好差1天；输出 matched pairs / valid day pairs |
| 9 | LAGE | 有效最大值减有效最小值 | mmol/L；依赖异常点QC |
| 10 | MAGE | Fernandes moving average/Service；短5点、长32点；候选峰谷回到清洗后原值算幅度 | 整个分析窗口统一样本SD，严格\>1SD；45/180 min gap，按segment长度加权；用R iglu参考核对，差异先查算法、不调参追平 |
| 11 | TIR | 3.9≤g≤10.0的有效时长/有效总时长 | `TIR_pct`、分钟数及valid_minutes |
| 12 | TAR/TAR1/TAR2 | TAR:g\>10；TAR1:10\<g≤13.9；TAR2:g\>13.9 | 各项独立从未舍入有效计数计算 |
| 13 | TBR/TBR1/TBR2 | TBR:g\<3.9；TBR1:3.0≤g\<3.9；TBR2:g\<3.0 | 独立计算；Level2不是Level3 |
| 14 | TITR | 3.9≤g≤7.8有效时长百分数 | 临床达标目标由项目另定 |
| 15 | GRI | `3×TBR2_pct + 2.4×TBR1_pct + 1.6×TAR2_pct + 0.8×TAR1_pct` | 输入均为0–100%；最终 `min(raw,100)` |
| 16 | TIR−TITR | 直接统计 7.8\<g≤10.0 时长百分数 | 建议名 `time_7p8_10_pct`；不减已四舍五入百分数 |
| 17 | 分时MEAN/SD/CV | 夜\[00:00,06:00)、日\[06:00,24:00)分别计算 | 子窗独立覆盖；字段注明 `00to06`/`06to24` |
| 18 | 夜间谷值及时间 | 每个合格夜窗取有效最低值及其首次发生时间 | 患者×夜长表，留date/start/end/valid_minutes/coverage，可加重复次数 |
| 19 | FBS-CV | 每日\[05:45,06:15)有效值中位数；跨≥2合格日求样本SD/均值×100 | 理论6槽至少4有效；仅住院清晨 proxy，不等同实验室FPG |
| 20 | HYPO | 事件引擎 \<3.9连续≥15 min，≥3.9连续≥15 min恢复 | NA/gap断开；详见下一节 |
| 21 | EX HYPO | \<3.9连续≥120 min；另 \<3.0连续≥120 min | `extended_hypo_lt3p9_120` 与 `prolonged_level2_lt3p0_120` |
| 22 | EX HYPER | \>13.9连续≥120 min 的独立period | `prolonged_hyper_gt13p9_120`；旧含混名停用 |
| 23 | LV2 HYPO | \<3.0连续≥15 min，≥3.0连续≥15 min恢复 | 嵌套于普通episode仍单独记录 |
| 24 | HYPO_COND | 从事件级 nadir 严格小于3.0–3.8累计阈值派生 | 次数和0/1异名同时输出；足够观测且未发生=0；覆盖不足NA；累计必须单调 |
| 25 | P5/P25/P50/P75/P95 | 有效值分位数，固定 linear 插值 | 写入方法版本；不静默改method |
| 26 | global_min | 窗口最低有效清洗值 | `min_value_qc_flag` 标记\<1.8或邻近缺口 |
| 27 | \<1.8 QC字段 | 区分有效正值\<1.8、0/负/错误码等无效值 | `below_1p8_valid_count` 等属于数据质量，不是临床结局 |
| 28 | HYPO日/夜拆分 | 全天事件起点时段另存；夜窗内独立重新检测 | `event_start_period` 与 `night_window_event` 不混用 |
| 29 | 夜间HYPO_COND | 只用独立夜窗识别的事件/nadir 派生 | 充分无事件=0，不足=NA |
| 30 | 出院前72h Full特征 | \[discharge−72h, discharge)的 MEAN/CV/pooled LBGI | `mean_pre72h`、`cv_pre72h_pct`、`lbgi_pre72h` |
| 31 | 出院前24h昼/夜P5 | \[discharge−24h, discharge)内日、夜各自取linear P5 | `day_p5_pre24h`、`night_p5_pre24h`，子窗各自70% |
| 32 | D1/D3及变化 | pump-start D1=\[0,24h)、D3=\[48,72h)，delta=D3−D1 | Full泵字段与CGM-start Sparse字段严格异名；D1/D3分别查覆盖 |

## 3. 事件引擎的可复算规则

| 类型 | 启动 | 恢复/结束 | 计数与证据 |
| ------------------ | ------------------ | ------------------ | ------------------ |
| `hypo_episode_lt3p9` | g\<3.9真实连续≥15 min | g≥3.9真实连续≥15 min | 保存实际起止、nadir、窗口、左右截断 |
| `level2_period_lt3p0` | g\<3.0真实连续≥15 min | g≥3.0真实连续≥15 min | 可嵌套于普通episode |
| `extended_hypo_lt3p9_120` | g\<3.9真实连续≥120 min | 遵从普通episode恢复边界 | 同一未恢复episode只计1次；内部每段连续≥120 min单独存起止及父事件ID |
| `prolonged_level2_lt3p0_120` | g\<3.0真实连续≥120 min | 对应Level2恢复边界 | 同一未恢复period只计1次，内部连续低值段分别记录；不得称Level3 |
| `prolonged_hyper_gt13p9_120` | g\>13.9真实连续≥120 min | 连续高值period结束 | \[此前 Lifan 裁定\] 不用旧10.0恢复阈值 |

**共同规则：** 窗口左闭右开；一分钟聚合后的连续事件使用组首五分钟时刻，每点支持随后至多5分钟并受下一个观测、NA/缺口与窗口末端裁剪。跨午夜连续事件不因日期切断；遇 NA/gap 不合并。窗口内达到门槛的左右截断事件可以计一次，同时记录 censored 与 complete_event_flag。夜间结局在 \[00:00,06:00) 与研究窗口的交集内独立重新判定；若被研究窗口截断，覆盖分母也取交集。白天事件起点在夜间与夜间独立事件是不同字段。正式0/1结局还要求对应观察窗充分，覆盖不足为 NA。

**来源说明：** 表内甲方阈值来自 `01.md`，一分钟连续支线事件使用组首规划时刻，夜窗允许截断并独立计算局部覆盖。此前其他补充规则不自动继承，逐项状态见 05。


## Sparse与Full

Sparse20：最早有效正值原始时间作为CGM起点，D1/D3各四点，出院前72h十二点。每日06:30、11:00、17:30、22:00，在所属窗内±10分钟取唯一最近原始有效点，等距/无候选NA。D1均值要求4/4，D3-D1均值差要求8/8，pre72h均值/最小值/样本CV要求12/12。

Full7：mean_pump_d1、delta_mean_pump_d3_d1、mean_pre72h、cv_pre72h_pct、lbgi_pre72h、day_p5_pre24h、night_p5_pre24h。泵D1=[0,24h)、D3=[48,72h)，锚点为泵开始，停止≤开始只空泵字段。
