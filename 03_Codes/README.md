# CGM Metric Library 2.0.0

Python package for traceable continuous glucose monitoring metrics. The repository
README provides project history, installation, configuration and deployment in
Chinese and English. From this directory, run `uv sync --frozen --python 3.14.7`
and `uv run --frozen pytest -q`. Revision 261109 exports results to four decimal
places and sets the Excel font to Times New Roman.

独立 Python 包。规范与完整操作说明见上一级 `_SPEC/`、`04_Manuals/`。
执行 `uv sync --frozen`、`uv run pytest`、`uv run cgm-library --help`。
真实计算资产不进入 Git；MAGE 的参考验证状态随交付说明。
